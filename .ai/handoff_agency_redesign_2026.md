## r128/r134 runtime arrangement
The three Neuform effects render inside **sandboxed srcDoc iframes** (authored architecture) — each document is its own realm, so no THREE global can leak or collide, and this site's three variants are in fact raw WebGL/Canvas 2D (no THREE at runtime at all). The one bare THREE dependency is the dock's *glass* field (`glassParticleField.ts` imports `three128`), which this site never mounts (variant-gated dynamic import). Resolution is provided without touching registered files: npm alias `three128 → three@0.128.0` (+ typed via `types-three128 → @types/three@0.128.0` and `src/shaders/three128-types.d.ts`). No THREE bytes ship to the client. r134 is referenced by other catalogue variants only — nothing loads it. Build plumbing: Turbopack `raw-loader` rule + webpack `asset/source` fallback for the authored `?raw` imports; unused sibling sources the hosts import are satisfied by documented build-resolution stubs (never rendered).
