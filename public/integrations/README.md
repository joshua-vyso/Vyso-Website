# Third-party marks

Every SVG in this folder is a third-party brand mark shown in the home-page
integrations marquee (`components/marketing/IntegrationsMarquee.tsx`) and on
`/integrations`.

**Use.** These marks are reproduced under nominative fair use, solely to
identify the third-party services Vyso is built to connect with. No affiliation,
sponsorship or endorsement by any of these companies is implied. All trademarks,
logos and brand names are the property of their respective owners.

**Rules for adding or replacing a mark.**

- Take it from a source you can cite — the vendor's own brand page, or a
  Wikimedia Commons file page whose licence statement you have read.
- Record the exact source URL and the licence/trademark note in an HTML comment
  at the top of the file (see `gpt.svg` and `outlook.svg`).
- Never recolour, distort, rotate or add effects to a mark. The marquee only
  greys/dims non-focused logos, which is a presentation state, not an alteration
  of the mark itself.
- If a vendor asks us to remove or change their mark, do it.
